# Network Protocols

This folder covers foundational network and application protocols that make Internet communication possible—including ARP (RFC 826), FTP, SMTP, HTTP, SSL/TLS, HTTPS, DNS, and DHCP (DORA) along with the 4 required host configuration parameters.

## Contents

- [`network_protocols_study_notes.md`](./network_protocols_study_notes.md) — Core network and application protocols (`ARP`, `FTP`, `SMTP`, `HTTP`, `SSL`, `TLS`, `HTTPS`, `DNS`, `DHCP`), the 4 essential host connectivity settings, and a quick-reference summary table.
- [`How to send HTTP request using Telnet manually.md`](./How%20to%20send%20HTTP%20request%20using%20Telnet%20manually.md) — Hands-on breakdown of HTTP vs. HTML, manually sending an HTTP `GET` request over TCP Port 80 with `telnet`, reading raw responses, and ASCII vs. binary/encrypted protocol limits.
