# OSI Model

This folder covers the OSI Model (Layers 1–7), MAC vs. IP addressing, ARP, TCP/UDP ports, encapsulation/decapsulation, and how packets traverse hops from a client PC through routers to a destination host.

## Contents

- [`00-osi_model_and_addressing_part1.md`](./00-osi_model_and_addressing_part1.md) — Overview of the OSI Model, Layers 1–3 (Physical, Data Link, Network), MAC vs. IP addressing, ARP, and hop-by-hop packet traversal.
- [`01-osi_model_part2.md`](./01-osi_model_part2.md) — Layers 4–7 (Transport ports & 4-tuple stream isolation, Session/Presentation/Application), OSI vs. TCP/IP model, and encapsulation/decapsulation.
- [`the forgotten layers of osi model.md`](./the%20forgotten%20layers%20of%20osi%20model.md) — Deep dive into Layers 5–7 (Session cookies vs. mainframes, Presentation bit interpretation & Extended ASCII, Application commands), HTTP vs. FTP comparison, and why TCP/IP combines L5–L7.
