# How Switches Work

This folder covers Layer 2 switching fundamentals, MAC address tables, the three core switch actions (learning, forwarding, and flooding), unicast vs. broadcast frames, VLANs, and how multiple switches communicate using access and trunk (802.1Q) ports.

- [`switches_part_2.md`](./switches_part_2.md) — Unicast vs. broadcast frames, VLANs, multi-switch learning/forwarding, and access vs. trunk ports (802.1Q tagging).
