# Everything Routers Do

This folder covers Layer 3 routing fundamentals, RFC standards, how routers use routing tables and Longest Prefix Match to forward packets across networks, route population methods (Directly Connected, Static, Dynamic), and dynamic routing protocols.

## Contents

- [`everything_routers_do_part1.md`](./everything_routers_do_part1.md) — Router core functions, RFCs (importance and structure), routing tables and components, route population methods (`C`/`L`, Static, Dynamic), and overview of RIP, OSPF, EIGRP, IS-IS, and BGP.
