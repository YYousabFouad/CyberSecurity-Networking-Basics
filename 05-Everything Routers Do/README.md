# Everything Routers Do

This folder covers Layer 3 routing fundamentals, network nodes, RFC standards, how routers use routing tables, Longest Prefix Match, and ARP tables to forward packets across networks, route population methods (Directly Connected, Static, Dynamic), dynamic routing protocols, and how interconnected networks form the Internet.

## Contents

- [`everything_routers_do_part1.md`](./everything_routers_do_part1.md) — Router core functions, network nodes (types and topology concepts), RFCs (importance and structure), routing tables and components, route population methods (`C`/`L`, Static, Dynamic), and overview of RIP, OSPF, EIGRP, IS-IS, and BGP.
- [`everything_routers_do_part_2.md`](./everything_routers_do_part_2.md) — Router ARP tables, step-by-step packet forwarding walkthrough (request & response across R1/R2), multi-router scaling, Layer 2 vs. Layer 3 header behavior, and how networks and routers form the Internet.
