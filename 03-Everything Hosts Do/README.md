# Everything Hosts Do

This folder covers how directly connected hosts and router-connected hosts communicate, how hosts use subnetting to distinguish local vs. remote traffic, how ARP and DNS resolve addresses, and how Layer 2 (hop-by-hop) and Layer 3 (end-to-end) headers behave across routers.

## Contents

- [`direct_host_connections_in_details.md`](./direct_host_connections_in_details.md) — Direct host-to-host connections, subnetting math (CIDR, block size, usable hosts), ARP cache/resolution, and DNS name resolution.
- [`hosts_connected_through_a_router.md`](./hosts_connected_through_a_router.md) — Hosts connected through single and multiple routers, ARP for the default gateway, and Layer 2 hop-by-hop vs. Layer 3 end-to-end packet delivery.
