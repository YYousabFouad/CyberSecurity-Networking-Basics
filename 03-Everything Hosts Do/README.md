# Everything Hosts Do

This folder covers how directly connected hosts communicate without switches or routers, how hosts use subnetting to distinguish local vs. remote traffic, and how ARP and DNS resolve addresses before data transmission.

## Contents

- [`direct_host_connections_in_details.md`](./direct_host_connections_in_details.md) — Direct host-to-host connections, subnetting math (CIDR, block size, usable hosts), ARP cache/resolution, and DNS name resolution.
